businessRule.button.update=Update
businessRule.custom=Custom Script
businessRule.desc.action=Groovy expression. It specifies an action of current Business Rule. It is possible to write some records to Processing Log or update some products here.
businessRule.desc.description=This is text explanation of current Business Rule
businessRule.desc.globalRule=This flag specifies the number of times current Business Rule will be executed. If it is checked the rule is considered global and will be executed only once for one catalog. If it is unchecked the rule will be executed for each product in a catalog. Global rules are executed after Business Rule Engine has processed all catalog products with each common rule from the current Business Rule List.
businessRule.desc.id=ID of current Business Rule.
businessRule.desc.listId=ID of the Business Rule List to which the current rule is assigned.
businessRule.desc.pathToCustomScript=Customization Area relative path to custom Groovy script. This script is executed during processing the Business Rule.
businessRule.desc.positiveAction=This flag specifies which rule execution result will lead to current Business Rule action execution. If it is checked the action will be executed in case rule execution finishes successfully and the action will be skipped in case rule execution finishes with error. If this flag is unchecked the action will be executed only if the rule returns error result and skipped if the rule returns successful result.
businessRule.desc.precondition=Groovy expression. It specifies a precondition of current Business Rule. Some conditions can be checked here. Depending on these conditions further execution of current Business Rule can be stopped or continued. If this section returns false a rule and an action of current Business Rule will be skipped.
